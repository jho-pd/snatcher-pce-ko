# 스내처 (Snatcher) PC엔진 CD-ROM² 한글패치

Snatcher CD-ROMantic (PC엔진 SUPER CD-ROM², 1992, 코나미) 한국어 패치입니다.

본 패치는 원본 일본판 디스크에서 텍스트를 직접 뽑아내고, 한글 폰트, 대사창 처리, 음성 자막 엔진, 번역까지 처음부터 새로 만든 독자 작업물입니다. 번역은 일본어 음성과 원문만 기준으로 했습니다.

- 다운로드: [Releases](https://github.com/jho-pd/snatcher-pce-ko/releases) 에서 최신 버전을 받으세요.
- 이 저장소에는 게임 데이터가 없습니다. 갖고 계신 일본판 원본 디스크 이미지에 패치를 적용해서 씁니다.

## 패치 방법 (Windows, 권장)

릴리스의 `Snatcher_KO_Patch.exe` 하나만 있으면 됩니다.

1. 원본 이미지가 있는 폴더에 exe를 넣고 더블클릭합니다. (또는 원본의 cue/ccd 파일을 exe 위에 끌어다 놓습니다)
2. `Snatcher_KO` 폴더가 생기면 그 안의 `Snatcher_KO.cue` 를 에뮬레이터에서 엽니다.

지원하는 이미지 형식:
- 단일 BIN/ISO + cue (631,563,744바이트, MD5 `959c78130d97d4308c6586e06d0fa056`)
- 트랙별로 나뉜 bin + cue (프리갭 포함/미포함 모두)
- CloneCD (ccd/img/sub)

드라이브마다 다른 오디오 밀림(오프셋)과 프리갭은 자동으로 맞춥니다. 기준 원본과 똑같이 되돌려지면 결과 MD5는 `1244bf5df3443223f7b1e0c9c39ef041` 입니다. 오디오만 조금 다른 이미지도 게임 데이터가 같으면 패치됩니다. (이때는 결과 해시만 달라집니다)

서명이 없는 프로그램이라 처음 실행할 때 "Windows의 PC 보호" 창이 뜨면 **추가 정보 > 실행**을 누르세요. 소스 코드는 [patcher/](patcher/) 에 있습니다. (Go, `go build` 로 직접 빌드할 수 있습니다)

xdelta를 직접 쓰셔도 됩니다. 이때는 위의 단일 BIN/ISO(MD5 일치)가 필요합니다. 자세한 내용은 릴리스 zip 안의 README.md를 봐 주세요.

바이오스 패치는 필요 없습니다. 원판과 같이 SUPER CD-ROM² System 3.0 바이오스(syscard3.pce)만 있으면 됩니다.

## 신경 쓴 점

- **가독성**: 대사창 글줄 정리, 음성 장면 자막 추가, 실제 플레이로 맞춘 자막 타이밍과 초상화 위치에 따른 자막 배치
- **의미 전달을 위한 적극적 의역**: 장면의 뜻과 인물의 말투가 한국어로 자연스럽게 전해지도록
- **가우디 영문 자판**: 인명 검색, 비밀번호 입력을 영문 자판으로도

## 제작

마이콜 & 은유 아빠. 디스크 분석, 번역 초안, 자막 엔진과 도구 제작은 AI(Anthropic의 Claude)와 함께 했고, 번역 수정과 처음부터 엔딩까지의 플레이 검수는 직접 했습니다.

오류 제보: [Issues](https://github.com/jho-pd/snatcher-pce-ko/issues)
